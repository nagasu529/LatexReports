\begin{abstract}
This study proposes an explainable AI-based decision support system (DSS) for precision allocation of agricultural skill development programs. The framework integrates K-Means clustering for farmer segmentation, Random Forest modeling for predicting skill improvement, and SHAP analysis for interpretable feature attribution within a unified Segment–Attribute–Recommend pipeline. The proposed model achieved an R\textsuperscript{2} of approximately 0.62 in predicting skill outcomes. Cluster-level SHAP values were further transformed into interpretable IF–THEN rules, enabling transparent and actionable recommendations for extension practitioners. The results highlight substantial heterogeneity in farmer characteristics and reveal non-linear, segment-specific drivers of training effectiveness. The framework demonstrates how explainable machine learning can be operationalized into deployable decision logic to support data-driven agricultural extension systems.
\end{abstract}
